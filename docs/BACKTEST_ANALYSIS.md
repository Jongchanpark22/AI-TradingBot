1. **TRENDING_DOWN 레짐 신호 차단** → 즉각 253건 제거, 전체 품질 향상
2. **RSI 55+ 진입 억제** → 3,525건 중 하위 필터링

4. **부분 청산 가능성 높은 신호 선별** → 승률 90% 구간 극대화
5. **PENGU·BORA·WIF 계열 차단** → 변동성 과대 코인 필터
