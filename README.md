# 주식 비서 (AI Market Companion)

> **AI가 돈 벌어주는 봇이 아닙니다. 내 종목에 무슨 일이 일어나는지 쉬운 말로 알려주는 비서입니다.**
> 수익을 약속하는 자동매매 대신, **이해·주의력·접근성**을 드립니다.

---

## 무엇인가 (그리고 무엇이 아닌가)

- ✅ 내 종목을 대신 지켜보고, 무슨 일이 왜 일어났는지 쉬운 말로 설명
- ✅ 차트·지표·뉴스·경제 일정을 하나로 묶어 매일 아침 루틴을 대신
- ✅ 사용자가 알림·전략·테마를 직접 커스텀
- ❌ 자동매매·일임매매 아님 — 매매는 사용자가 직접
- ❌ 수익 보장·목표주가 제시 아님 — 정보와 해석을 제공

**핵심 전환:** "AI가 돈 벌어줌" → **"AI가 대신 지켜보고 정리·설명해줌."**

---

## 누구를 위해

전문 트레이더가 아닌, **이미 주식·코인을 하고 있지만 차트·수급·용어를 깊이 보긴 어려운 사람.**
본업이 있고 재테크로 투자하는 직장인 (특히 2030).

---

## 4대 기능 (MVP)

| # | 기능 | 한 줄 |
|---|---|---|
| 1 | 내 종목 관리 + 전망 | 보유 종목 현황 + "과거 유사 패턴에선 이랬다" (참고 통계·예측 아님) |
| 2 | 차트·지표·커스텀 알림 | RSI·MA·지지저항 오버레이 + 조건 알림 + KOSPI/NASDAQ/BTC 흐름 |
| 3 | 뉴스·경제 캘린더 | 테마별 실시간 뉴스 + 내 종목 연결 + FOMC·실적·공시 일정 |
| 4 | AI 기업 리포트 | 공개 재무데이터 기반 쉬운 리포트 생성 (목표주가·매수의견 없음) |

> v2+: "이 종목이 왜 움직였나" (뉴스 RAG 설명), 커뮤니티, 백테스트 랩 공개.

---

## 핵심 원칙

1. **정확성** — 숫자·사실은 실데이터. "사실(데이터)"과 "해석(LLM)"을 항상 분리. LLM은 설명만, 숫자를 만들지 않음 (RAG).
2. **실시간성** — 이벤트 구동. 가격=WebSocket, 뉴스=폴링, 경제일정=스케줄. 알림=푸시.
3. **정직함** — 예측은 "과거 통계(참고용)"로만. 인과 단정·수익 약속 없음.
4. **개인화** — 범용 피드가 아니라 "내 종목·내 테마" 중심.

---

## 차별점

- vs TradingView — 차트로 싸우지 않음. 그 위에 **설명·개인화 레이어**.
- vs 뉴스 집계 서비스 — 뉴스를 **내 종목에 연결 + 쉬운 설명**으로 차별화.
- 공통 빈틈: 둘 다 사용자가 안다고 가정 → 우리는 **친근함 + 내 종목 맞춤**.

## 아키텍처

```
[모바일/웹 앱]              ← 사용자 경험
        │
[백엔드 API — Spring :8080] ← 기존 트레이딩 엔진 재활용
   ├─ 시세/캔들 수집 (업비트 WebSocket·API)
   ├─ 지표 계산 (RSI/EMA/MACD/ATR/볼린저 등)    ← 기능2 근거
   ├─ 신호 → 자동매매 대신 "커스텀 알림 트리거"로 전환
   ├─ 백테스트 엔진 → 기능1 "과거 통계" 근거
   └─ ML → "참고 신뢰도" 보조 지표
        │
[뉴스·데이터 파이프라인 — Python]  ← 신규
   ├─ 뉴스 수집·테마분류·종목매칭 (기능3)
   ├─ 재무데이터 수집·지표계산 (기능4)
   └─ LLM API 호출 (리포트/설명) — 실데이터 RAG
```

기존 업비트 연동·WebSocket, 지표 계산기, 백테스트 엔진, ML 파이프라인, 리스크 관리 로직은 **전부 살아남아** 비서의 데이터 근거가 됩니다. 자동매매 주문 실행부만 `trading.execution.enabled` 설정으로 on/off합니다.

## 재사용되는 기존 엔진

| 기존 클래스/기능 | 비서에서의 역할 |
|---|---|
| `HybridSignalAnalyzer` | 알림 조건 평가 엔진 |
| `RegimeClassifier` | 시장 레짐 표시 (기능2) |
| `BacktestEngine` / `MultiStrategyBacktestEngine` | 과거 유사 패턴 통계 (기능1) |
| `PositionMonitor` + WebSocket | 실시간 가격 감시 → 알림 트리거 |
| `Indicators` | 차트 지표 오버레이 (기능2) |
| ML 파이프라인 (ai-service) | 참고 신뢰도 보조 지표 |
| `StrategyRegistry` / `Strategy` | 커스텀 알림 조건 정의 기반 |

## 기술 스택

| 영역 | 기술 |
|---|---|
| 백엔드 | Java 17, Spring Boot 3.2, JPA/Hibernate, OkHttp3 |
| ML·데이터 파이프라인 | Python 3.11, XGBoost, pandas, FastAPI |
| 캐시 | Redis (캔들·티커·신호 TTL 10분) |
| DB | MySQL 8 |
| 코인 데이터 | 업비트 API (확정) |
| LLM | Gemini Flash 무료 초기 → 추후 전환 가능 (LlmClient 추상화) |
| 공시·재무 | DART Open API (무료·공식) |
| 프론트·차트 | 확정 예정 |
| 국내주식·지수 데이터 | 확정 예정 |

## 데이터베이스 주요 테이블

| 테이블 | 설명 |
|---|---|
| `candles` | 캔들 데이터 (15분/1시간/4시간) |
| `strategy_run_logs` | 신호 평가 로그 — feature JSON, ML 확률 포함 |
| `trade_history` | 체결 이력 (PnL, ATR, signal_id 연결) |
| `positions` | 보유 포지션 (손절가, 최고가, ATR) |
| `orders` | 주문 이력 |

> 신규 추가 예정 (확정 후 스키마 변경): `UserHolding`, `Watchlist`, `UserAlert`, `NewsItem`
